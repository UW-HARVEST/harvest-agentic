**Claude Code async sub-agent bug** Claude Code launches sub-agents asynchronously by default. In this headless (`claude -p`) session that is fatal: ending your turn with an asynchronous sub-agent call ends the entire session instead of waiting for the sub-agent to finish.
Therefore, you must launch every sub-agent with `run_in_background: false` (synchronous). You are still encouraged to launch multiple sub-agents in a single turn when parallel execution is beneficial. This rule also applies to sub-agents that a sub-agent launches. Sub-agents do not see this warning. Copy this whole warning into every sub-agent prompt.
